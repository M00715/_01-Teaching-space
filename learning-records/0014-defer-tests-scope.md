# 0014 · 主动质疑"测试是否现在必学" + 测试代码未看懂

日期：2026-10-16
状态：已决策（测试延后）

## 学习者原话（两个问题）
1. 第 3 课那段 `@SpringBootTest` 代码**依旧不会写、看不懂**。
2. 质疑：「**对于当前学习阶段，有必要现在就学测试类的编写吗？**」

## 教师判断
- **问题 2 学习者是对的，值得表扬。** 这是 `teach` 技能强调的元认知/范围控制能力：盯住 mission 学，不被"顺带技能"带偏。
  - Mission = 独立写出 Spring Boot + MyBatis 的 REST CRUD。
  - 自动化测试是**独立技能**，对"能写 CRUD"**非必需**；验证手段 curl / Postman 已足够。
  - 结论：**测试正式延后**，列为加分项，待 CRUD 写顺后再回补。已写入 `MISSION.md` 的 Out of scope。
- **问题 1 的处理**：不要求现在会写，但把代码**去神秘化**（大白话拆解），避免它变成心理负担。
  - 拆解：整段 = 启动应用(@SpringBootTest) → 注入 Service(@Autowired) → 存一条 → 查出来 → 检查名字(assertEquals)。
  - 只有 4 个新注解/API：`@SpringBootTest`（启动应用）、`@Autowired`（已会）、`@Test`（标记自动跑）、`assertEquals`（自动化的 if 判断）；其余全是第 2 课老朋友。

## 对第 3 课的调整（已落盘）
- 五节标题标注"（本节属进阶，可延后）"；"自动化测试"条目标注"进阶·可延后"。
- 测试代码块下方加「别被吓到」澄清卡片（4 个新东西 + 大白话翻译）。
- 动手任务③ 标注"（进阶·可选）…不会可以先跳过"。
