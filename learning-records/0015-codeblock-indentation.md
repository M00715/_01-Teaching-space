# 0015 · 课件代码块缩进问题修复（格式化反馈）

日期：2026-10-16
状态：已修复

## 学习者反馈
"你用 html 写的课件，对于设计代码的部分能否将代码添加缩进，不然看着很凌乱。"

## 根因
`assets/style.css` 的 `.codeblock` 规则**缺少 `white-space` 声明**。浏览器默认把代码里的
换行符与行首空格全部压缩成单个空格，导致多行代码挤成一团、看不出 `{}` 层级。

## 修复
给 `.codeblock` 增加 `white-space: pre-wrap;`（保留换行与行首缩进，长行仍可折行）+ `tab-size: 4;`。
一处修改，第 1/2/3 课所有 `<div class="codeblock">` 立即恢复源码中已有的层级缩进。

## 结论
- 各课源码里其实**已经写了缩进**（如第2课 User 类字段、UserService 方法体），只是被 CSS 隐藏。
- 后续新增课件代码时，直接在源码里正常缩进即可，CSS 会自动保留。
- 若某段代码仍显扁平，多半是那段源码本来就没缩进，再单独补。
